The six new tenants have editable public profiles with bios, budgets, and living habits. Luis, Bea, and Jerome start with assigned rooms so they can use maintenance, announcements, and bills. Create bills, requests, and messages live during the demo.

Existing browser records and profile edits are preserved. Juan and Ana retain any tenancy you already approved. If a preset room is occupied, a new resident uses another available room in that property; if the property is full, approve a room manually after making space. Removed demo tenancies are not recreated on reload.

## Which accounts to use

| Demonstration | Accounts |
|---|---|
| Assignment walkthrough: announcement, maintenance, offline delivery/catch-up | Maria, Luis, Bea — follow the [website demo guide](UPa_Website_Demo_Guide.md). |
| Filter announcements between properties | Maria posts to Casa Jaro: Luis and Bea receive it; Jerome does not. Post to Molo: Jerome receives it. |
| Rental requirements, application and approval | Carlo applies to Casa Jaro; Maria reviews and assigns a room. Miguel and Sofia are spare applicants. |
| Profile, bio and community posts | Miguel or Sofia edits their profile and publishes a post. |
| Mutual roommate interest | Miguel and Sofia express interest in each other, then open their conversation. Use the same browser profile when switching these accounts because roommate decisions are stored locally. |
| Private owner/tenant messages | Maria and any tenant. Use separate browser profiles or devices to show live delivery. |

Use **separate browser profiles or devices** for the assignment walkthrough. For example: Maria in Edge, Luis in Chrome, and Bea in Edge InPrivate. All devices should use the same ngrok address; on the host computer the website is **http://127.0.0.1:8003/**.

Refresh existing website windows once after this update to load the new account list. Signing out and back in lets you change participants without resetting demo records.
